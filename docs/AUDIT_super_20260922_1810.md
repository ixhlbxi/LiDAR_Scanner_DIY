### Read this first — the shape of the result

1. **The code has never been run end-to-end on hardware, and it shows.** Thirteen of the fourteen high-severity correctness findings are in paths that unit tests mock away: the watchdog cannot exit the process, the systemd units kill a correctly configured rover within 90 s, the default config writes to a directory the unit file forbids, the camera call would raise `TypeError` on a real Picamera2, and the georef export produces a flat plane instead of a volume. None of these can be seen from the 272 green tests. **Recommendation: treat T1-001..T1-012 and T2-001 as a single "first-boot blocker" batch** before any other work; they are all small.
